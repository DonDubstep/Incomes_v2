# Incomes API

**Base URL:** http://localhost:8001/api

## Эндпоинты
- `GET /5` 
- `GET /6`
- `GET /7`
- `GET /8`
- `GET /9`

---

## GET `/5`
Возвращает общую сумму денег на текущий момент. Результат высчитывается как сумма всех денег, переведённой в рубли за последний введённый период времени (месяц)

### Ответ
int - amount_of_money

---

## GET `/6`
Возвращает общую сумму дохода за последний период вермени (месяц). Результат высчитывается как сумма доходов, переведённой в рубли за последний введённый период времени (месяц)

### Ответ
int - income

### Не хвататет перевода валюты в рубли

---

## GET `/7`
Возвращает разницу общей суммы относительно двух последних периодов времени (месяцев). Т.е. прирост или уменьшение общей суммы относительно предыдущего периода времени (месяца)

### Ответ
int - amount_change

---

## GET `/8`
Возвращает общую сумму денег на текущий момент в каждой валюте

### Ответ
currency string Название валюты
total float Общая сумма в рублях
type_money string Наличные/безналичные

---

## GET `/9`
Возвращает три последних дохода.

### Ответ
description string Описание
amount float Общая сумма в рублях
date string Дата пополнения

### Не хвататет перевода валюты в рубли 
---

## GET `/10`
Возвращает сумму доходов за все периоды. N задается как аргумент GET-запроса
### Ответ
amount int Общая сумма в рублях

---

## GET `/11`
Возвращает доходы за все периоды (месяцы) в рублях.
### Ответ
period string Месяц + год
amount int Общая сумма в рублях

```json
[
    {"period": "Август 2026", "amount": 210000},
    {"period": "Июль 2026",   "amount": 180000},
    ...
]
```

---

## GET `/12`
Возвращает наибольшее, наименьшее и среднее значение дохода за выбранный период N
### Ответ
max_income int Максимальный доход за период
min_income int Минимальный доход за период
mean_income int Средний доход за период
